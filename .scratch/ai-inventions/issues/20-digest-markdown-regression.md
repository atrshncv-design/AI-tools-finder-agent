# Ticket 20 — Дайджест 19.08 не доставлен: незакрытый Markdown + мёртвые тесты + сгоревший архив

## Status: done

## Симптом (2026-08-19 06:00 UTC)
Крон daily-digest отработал, но Telegram отклонил сообщение во ВСЕХ трёх чатах:
`HTTP 400 can't parse entities: Can't find end of the entity starting at byte offset 2512`.
Клиент и владелец не получили утренний дайджест вообще.

## Корневой анализ
1. **Незакрытая `*`** — в `6595675` при переформатировании шапки потеряна
   закрывающая звёздочка: `🌅 *Утренний дайджест научного агента` (без `*` в конце).
   В старом коде (`b11d749^`) она была. Telegram parse_mode=Markdown требует парность.
2. **Тесты дайджеста никогда не запускались**: `scripts/hermes/daily-digest.test.ts`
   лежит вне include-глобов vitest (`api/**`, `src/**`). Прогон «115/115» их не содержал,
   поэтому регрессия прошла незамеченной.
3. **Архив сгорал при провале доставки**: `digestArchiveSentAt` выставлялся даже когда
   fan-out упал (CHAT_IDS>0 достаточно) — пул архивных статей помечался «отправленным»
   без фактической отправки.
4. Попутно вскрылись (теми же ожившими тестами):
   - `splitTelegramText` резал по слову из-за `cut < 200` (guard задуман против
     огрызков, но ломал перенос строк);
   - `main()` запускался при импорте модуля тестами → коннект к БД из vitest.

## Fix
- `daily-digest.ts`: закрыть `*` в шапке; архив помечать только при `okCount > 0`;
  `splitTelegramText` — `if (cut < 0) cut = maxLen`; `main()` только при прямом
  запуске (`import.meta.url === pathToFileURL(process.argv[1]).href`).
- `vitest.config.ts`: include `scripts/**/*.test.ts` — тесты дайджеста в прогоне.
- `daily-digest.test.ts`: регрессия «header bold is closed» + сканер парности
  legacy-Markdown (emphasis-чётность + каждый `]` замыкает `[текст](url)`).
