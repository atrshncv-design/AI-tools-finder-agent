# 14 — Cache-Control заголовки для статики (клиент видит старую версию)

Status: done  
Blocked by: none

## Задача

Клиент на ПК, Android и iOS не видит новый интерфейс: в мобильном меню нет 4-го пункта «Изобретения», клик по новости из раздела инструментов даёт «Инструмент не найден» (старый бандл ведёт новости на /tools/:id). Сервер при этом раздаёт новый бандл — проблема в кэшировании.

## Где менять

- `app/api/lib/vite.ts`

## Что сделать

1. `/assets/*` (хэшированные имена файлов) → `Cache-Control: public, max-age=31536000, immutable`.
2. Любой HTML-ответ (index.html через serveStatic и SPA-fallback) → `Cache-Control: no-cache` (обязательная ревалидация).
3. API-роуты не затрагивать (они смонтированы раньше).

## Критерий приёмки

- `GET /` и `GET /science` отдают `Cache-Control: no-cache`.
- `GET /assets/index-*.js` отдаёт `Cache-Control: public, max-age=31536000, immutable`.
- После деплоя мобильный браузер с очищенным кэшем показывает 4 пункта нижнего меню.
