# 17 — Дайджест: отдельный блок «Из архива» + текстовая ссылка на дашборд

Status: ready-for-agent  
Blocked by: none

## Задача

1. Счётчики секций дайджеста включают до 10 архивных статей (status='rejected', score>=50), которых нет в дашборде → клиент видит «в боте 16 новостей, на сайте 8».
2. В «сегодняшнем» сообщении клиент не видит кнопку «Открыть дашборд»: inline-кнопка одна, при длинном сообщении игрок её не находит.

## Где менять

- `app/scripts/hermes/daily-digest.ts`

## Что сделать

1. `buildDigest(items, archiveItems)`: секции и строка «опубликовано N» — только из свежих (24ч) статей; архив — отдельный блок «📚 Из архива» в конце, не больше 5 позиций, с пометкой что в счётчики суток не входят.
2. Запрос archiveItems: limit 5.
3. Fallback-логика заполнения пустых секций — только по свежим статьям.
4. В футер добавить текстовую строку с URL дашборда (работает даже без inline-клавиатуры).
5. Отметка digestArchiveSentAt после отправки остаётся.

## Критерий приёмки

- Юнит-тест: архивная статья не попадает в счётчик секции, выводится в блоке «Из архива».
- Текст дайджеста содержит URL дашборда.
