# 10 — Сохранять фильтры в URL для кнопки «Назад»

Status: done  
Blocked by: none

## Задача

При переходе «Назад» из детальной новости пользователь должен возвращаться к тому же отфильтрованному списку (freshness, категории, сферы).

## Где менять

- `app/src/pages/Home.tsx`
- `app/src/pages/Science.tsx`
- `app/src/pages/InventionTools.tsx`
- `app/src/components/FreshnessFilter.tsx`
- `app/src/components/CategoryFilter.tsx`

## Что сделать

1. Использовать `useSearchParams` для хранения состояния фильтров:
   - `freshness` — ключ freshness.
   - `categories` / `fields` / `spheres` — список slug через запятую.
   - Для `Science` — также `type` (классификация: new_tool, update и т.д.).
2. При изменении фильтра обновлять URL через `setSearchParams`.
3. При загрузке страницы читать фильтры из URL.
4. Кнопка «К списку новостей» в `NewsDetail.tsx` должна возвращать на URL с сохранёнными параметрами.

## Критерий приёмки

- Пользователь выбирает «За сутки» и категорию → открывает новость → нажимает «Назад» → видит тот же фильтр и позицию.
- Прямая ссылка с query-параметрами открывает страницу с уже применёнными фильтрами.
- Фильтры работают во всех трёх разделах.
