# 13 — Дайджест не отправляет статьи без summary

Status: done  
Blocked by: none

## Задача

Telegram-дайджест тоже показывает только название, если у статьи пустой summary. Нужно исключить такие материалы из дайджеста.

## Где менять

- `app/scripts/hermes/daily-digest.ts`

## Что сделать

1. Во всех трёх SQL-запросах (recentItems, archiveItems, fallback) добавить условие `summary IS NOT NULL AND summary <> ''`.
2. При необходимости обрезать summary до разумной длины (уже есть обрезка до 180 символов).

## Критерий приёмки

- В утреннем дайджесте не попадают статьи, у которых нет summary.
- Дайджест по-прежнему отправляется, даже если у какой-то секции нет качественных материалов (пустая секция просто не показывается).
