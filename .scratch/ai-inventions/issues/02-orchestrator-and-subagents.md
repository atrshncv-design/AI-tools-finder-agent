# 02 — Оркестратор и три нишевых субагента

Status: ready-for-agent  
Blocked by: 01-data-model-and-classification

Разделить обработку на оркестратор и три специализации: ИИ-инструменты, ИИ для
науки, ИИ для изобретений. Общий поток должен проходить через маршрутизацию, а
каждая специализация — иметь собственные поисковые запросы/источники без
дублирования публикаций.
