# 16 — Publisher публикует только статьи с саммари

Status: done  
Blocked by: none

## Задача

`scripts/publish_daily_batch.py` (крон 04:50 UTC) публикует статьи со status='pending' независимо от наличия summary. Из-за этого в продакшн попали 37 опубликованных карточек с пустым саммари (английские заголовки без описания). Дашборд их фильтрует, поэтому счётчики «в боте 16 / на сайте 8» и пустые ленты.

## Где менять

- `app/scripts/publish_daily_batch.py`

## Что сделать

1. Отбор к публикации: `status='summarized' AND summary IS NOT NULL AND summary <> ''` (статьи, прошедшие суммаризацию, но ещё не опубликованные).
2. Счётчики «pending» в логах — тоже по этому условию.
3. Балансировка по секциям и лимит 19/день остаются.

## Критерий приёмки

- После запуска publisher не публикует ни одной статьи без summary.
- Статьи со статусом pending остаются в очереди на суммаризацию ralph-loop.
