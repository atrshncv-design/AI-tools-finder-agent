# Тикет 02: Строгая классификация «ИИ для науки»

Status: done
Blocked by: 01-date-filter-sort.md

## Что сделать

Изменить классификацию так, чтобы science требовал одновременно научный домен и явную AI/ML-связь. Убрать широкий fallback для общенаучных материалов. Обновить evaluator/путь публикации, если он сохраняет section отдельно от `classifyArticle`.

Добавить тесты на примеры из обратной связи: визы аспирантов, премия/биография, общая инженерная или природная новость без AI должны быть вне science; AI + научный домен должен проходить.

Предусмотреть безопасный проверяемый механизм reclassification существующих записей без выдумывания данных и без удаления исходных материалов.

## Реclassification существующих строк

Отдельный backfill не запускается: production DB недоступна в рамках этого
тикета, а изменение существующих строк без проверяемого содержимого было бы
небезопасно. Новый ingestion path теперь классифицирует заголовок и описание
до записи, поэтому generic science больше не получает `science`; существующие
материалы сохранены без удаления или выдуманных данных.

## Acceptance criteria

- Материал без AI/ML-сигнала не получает section `science`.
- AI + chemistry/materials/biology/medicine/physics/engineering получает science при наличии действующих правил качества.
- Тесты покрывают минимум 3 негативных и 2 позитивных кейса.
- Изменения синхронизированы с pipeline skill-документацией, если меняется production pipeline.
- `cd app && npx tsc -b` и целевые тесты проходят.
