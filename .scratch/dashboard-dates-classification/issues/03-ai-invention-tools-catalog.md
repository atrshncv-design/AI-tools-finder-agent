# Тикет 03: В каталоге оставить только ИИ-инструменты

Status: done
Blocked by: 02-strict-science-classification.md

## Что сделать

Убрать смешивание новостных статей и каталога на странице `InventionTools`. Раздел должен читать только `invention_tools`. Проверить seed/классификацию/evaluation, чтобы новые элементы соответствовали критерию ИИ-инструмента для изобретательской или научно-инженерной работы, имели официальную http(s)-ссылку и описание.

Счётчик должен считать видимые каталоговые карточки после фильтров, а сортировка и freshness должны быть стабильными.

## Acceptance criteria

- Некрологи, лабораторные советы, новости политики и прочие статьи не отображаются в каталоге инструментов.
- В каталоге отображаются только записи из `invention_tools`.
- Все новые/валидируемые записи имеют официальную ссылку и непустое описание.
- Счётчик совпадает с количеством отображённых карточек.
- Добавлены тесты на отсутствие news-merge и на фильтр/сортировку каталога.
- `cd app && npx tsc -b` и целевые тесты проходят.
