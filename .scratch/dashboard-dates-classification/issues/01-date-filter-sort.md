## Что сделать

Исправить backend/frontend-расхождение: фильтр свежести уже использует `updatedAt`, но выдача сортируется по `publishedAt`, а карточки показывают `publishedAt`. Везде для новостей использовать `updatedAt DESC`, затем `id DESC`; в карточке показывать дату обновления/добавления в агенте.

Проверить все окна свежести, пагинацию и сохранение query-параметров.

## Acceptance criteria

- В `news.list` записи отсортированы по `updatedAt DESC, id DESC`.
- `day` отбирает только записи не старше 24 часов по `updatedAt`; аналогично остальные окна.
- Карточки Home/Science/Detail показывают `updatedAt`, а не `publishedAt`.
- InventionTools для каталоговых записей использует дату обновления каталога последовательно с фильтром.
- Добавлены/обновлены тесты, предотвращающие регрессию.
- `cd app && npx tsc -b` проходит.
