# Спецификация: релевантность разделов и устойчивость конвейера (science-relevance-fixes)

## Контекст

Повторная обратная связь клиента (25.08.2026) после эпика `dashboard-dates-classification`:

1. Раздел «ИИ для науки» пуст с 19 августа — новых карточек нет.
2. Раздел «Инструменты для изобретений» заполнен нерелевантным контентом:
   чисто медицинские новости (инъекция митохондрий), общенаучные материалы
   («гром сотрясает землю», «долгожители 110 лет»), бытовые ИИ-новости
   (инструменты Google для организации ужинов).
3. Часть материалов вообще не должна проходить фильтр — агент не отсеивает
   новости без связи с ИИ.
4. Утренний Telegram-дайджест не приходит с 19 августа, хотя новости публикуются.

Код-ревью (см. отчёт от 25.08) показало: симптомы вызваны связкой дефектов,
а не случайным сбоем; дата «всё сломалось» совпадает с коммитом `0388146`
(требование AI-сигнала для science) — правки того эпика встали лишь частично.

## Диагноз (подтверждён воспроизведением на примерах клиента)

- `classifyInvention` матчит бытовую медицинскую лексику (`терапи`, `клиническ`,
  `вакцин`, `препарат`, `лаборатори`, `автономн`, bare `алгоритм`, `discover`)
  и не требует признака ИИ → почти любая статья с полным текстом уходит в
  `invention-tools`.
- Научная статья без invention-слов получает Tier-1 +45 < гейта 50 → reject;
  со словом — reroute +25 → 70 → публикуется в чужом разделе. Отсюда
  асимметрия «наука пуста / изобретения захламлены».
- Гейты разъехались: `evaluate-news` одобряет при score ≥ 50, `manifest-gen`
  берёт ≥ 66 → диапазон 50–65 зависает в pending навечно.
- После получения полного текста `isScience`/секция не переоцениваются:
  RSS-сниппет без слова «ИИ» навечно отправляет AI×science новость в `ai-news`.
- Дайджест молчит при нуле записей за 24ч — тишина неотличима от аварии.

## Решения продукта

- Обязательный критерий для всех трёх разделов — **явная связь с ИИ**
  (термины EN/RU, названия моделей/инструментов). Новости без ИИ-сигнала
  не публикуются ни в одном разделе.
- Приоритет маршрутизации сохраняется: `invention-tools` > `science` > `ai-news`,
  но решение пересматривается по мере накопления текста (заголовок → описание →
  полный текст) и является **двунаправленным**: ошибочный reroute отменяется.
- Единый скоринговый гейт — одна константа для evaluate и manifest.
  Значение 50 (одобрение data-driven), релевантность обеспечивают ИИ-гейты
  классификации, а не завышенный порог баллов.
- Научные источники arXiv (все три ленты) и Naked Science оцениваются
  научной веткой скоринга; явный ИИ-сигнал даёт базовые +20 в science-ветке.
- Дайджест при нуле публикаций отправляет короткое «пустое» сообщение;
  код выхода отражает фактическую доставку.
- Существующие записи БД реклассифицируются отдельным скриптом (dry-run/apply),
  без удаления данных и без выдуманных значений.

## Не входит в объём

- Деплой на production и ручной запуск бэкфилла на проде (отдельное подтверждение).
- Изменение дизайна дашборда, структуры каталога `invention_tools`.
- LLM-классификация (конвейер остаётся детерминированным).
- Второй Telegram-бот / разбивка дайджеста по ботам.

## Проверка готовности

- `cd app && npx tsc -b` и `cd app && npx vitest run` — зелёные.
- Тесты классификаторов покрывают примеры из обратной связи клиента
  (негативные: митохондрии, долгожители, ужины Google; позитивные: AlphaFold,
  CRISPR+ML, «ИИ открыл материал»).
- Дайджест: тест пустого выпуска; существующие тесты форматирования зелёные.
- Документация (SKILL.md, ARCHITECTURE.md, AGENTS.md) синхронна с кодом.
