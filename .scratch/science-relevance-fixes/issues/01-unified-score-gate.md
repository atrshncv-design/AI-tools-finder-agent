# Тикет 01: Единый скоринговый гейт, ликвидация limbo

Status: done
Blocked by: —

## Проблема

`evaluate-news.ts` одобряет при `score >= 50` (`SCORE_GATE = 50`, понижен в
`207d690`), а `manifest-gen.ts` требует `score >= 66`. Статьи с баллом 50–65
одобрены, но никогда не попадают в LLM-конвейер и не отклоняются — вечный
pending-бэклог. Документация при этом описывает гейт «>65».

## Что сделать

- Создать `app/scripts/hermes/pipeline-config.ts` с единственной константой
  `SCORE_GATE = 50` (комментарий: единый источник правды для evaluate и manifest).
- `evaluate-news.ts`: импортировать константу вместо локальной.
- `manifest-gen.ts`: условие `gte(news.score, SCORE_GATE)`; комментарий
  привести к факту «>= gate».
- Побочный эффект зафиксировать в тикете: выровнение гейта выпускает
  существующий limbo-бэклог 50–65 в обработку естественным путём
  (по 50 статей за цикл ralph-loop).

## Acceptance criteria

- В коде нет второго числового порога одобрения; tsc фиксирует импорт.
- `npx tsc -b`, `npx vitest run` зелёные.
