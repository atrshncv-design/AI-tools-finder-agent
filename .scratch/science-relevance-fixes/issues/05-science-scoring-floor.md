# Тикет 05: Научная ветка скоринга — источники и база за ИИ-сигнал

Status: done
Blocked by: 02-hard-ai-relevance-gate.md

## Проблема

`arxiv`, `arxiv-cs-ai`, `arxiv-cs-et`, `naked-science` не входят в TIER1/TIER2 →
оцениваются технической веткой (HN/Reddit ≈ 0 баллов) и почти всегда
отклоняются. Даже Tier-1 (45) не дотягивает до гейта без бонусов. Раздел
«ИИ для науки» математически обречён на пустоту.

## Что сделать

В `evaluate-news.ts`:

- `TIER2_SCIENCE` дополнить: `arxiv`, `arxiv-cs-ai`, `arxiv-cs-et`,
  `naked-science` (+30, научная ветка скоринга вместо технической).
- В научной ветке добавить детерминированный критерий
  `science-ai-relevance +20` при явном ИИ-сигнале (после гейта тикета 02 сигнал
  гарантирован для не-exempt источников). Итоговый пол:
  Tier-1 = 65, Tier-2 = 50 ≥ гейта; чистая наука без ИИ отсечена гейтом 02.
- `ai-domain-intersection +15` сохранить как уточняющий бонус.

## Acceptance criteria

- AI×science новость с Nature проходит без invention-бонуса.
- arXiv/naked-science оцениваются научной веткой (видно в scoreBreakdown).
- Общенаучная новость без ИИ по-прежнему не публикуется (гейт 02).
