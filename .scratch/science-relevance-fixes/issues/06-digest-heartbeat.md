# Тикет 06: Дайджест — пустой выпуск и честный код выхода

Status: done
Blocked by: —

## Проблема

При нуле публикаций за 24ч `daily-digest.ts` не отправляет ничего и выходит
с кодом 0. Тишина неотличима от аварии — клиент 6 дней не понимал, жив ли бот.

## Что сделать

- `buildEmptyDigest()`: заголовок + «За последние 24 часа новых публикаций нет».
- В `main()` при пустом списке отправлять пустой выпуск всем получателям.
- Код выхода: 1 только если получателей > 0, есть что отправить и не доставлено
  никому (полный сбой); частичная доставка — 0 с логом. Stub-режим — 0.
- Тесты: пустой выпуск содержит признак «нет новых публикаций»; существующие
  тесты форматирования не сломаны.

## Acceptance criteria

- Любое утро бот присылает хотя бы пустой выпуск → тишина = авария = видно в
  cron-логе по exit code.
