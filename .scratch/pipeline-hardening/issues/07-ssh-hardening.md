# Тикет 07: SSH-харденинг сервера (требует подтверждения владельца)

Status: todo
Blocked by: —

## Проблема

Пароль root `1111111111`; auth.log показывает непрерывный брутфорс
(invalid user blank/paul и т.д.). Парольный вход SSH включён глобально.

## Что сделать (по выбору владельца)

Вариант A (рекомендуемый): отключить парольный вход SSH полностью —
ключ деплой-агента уже в authorized_keys и проверен:
`PasswordAuthentication no` в `/etc/ssh/sshd_config` и
`/etc/ssh/sshd_config.d/99-cloud-init.conf`, `systemctl reload ssh`.
Перед отключением убедиться, что у владельца настроен свой ключ.

Вариант B (минимум): сменить пароль на длинный (16+ символов) —
владелец делает сам, агент пароль не запрашивает и не хранит.

Дополнительно в обоих вариантах: проверить, что fail2ban включён
(`systemctl status fail2ban`); если отсутствует — предложить установку
с дефолтными jail для sshd.

## Acceptance criteria

- Выбранный вариант применён; вход агента по ключу работает после изменений.
- Вариант A: попытки пароля отклоняются сервером до промпта.
- Действие выполняется только после явного «да» владельца.
