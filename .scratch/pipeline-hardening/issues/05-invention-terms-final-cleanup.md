# Тикет 05: Финальная чистка INVENTION_TERMS по фактам бэкфилла

Status: done
Blocked by: —

## Проблема

После всех правок в «изобретения» всё ещё проходят стримы-пустышки и
обычные ИИ-новости. Факты из бэкфилла 25.08 (позиции, оставшиеся
в invention-tools или ушедшие туда):
`#573 AI NEWS LIVE`, `#1816 ПРЯМОЙ ЭФИР: …ВАЙБКОДИТЬ В CLAUDE И CODEX`,
`#2509 AI Security Costs Rise…`, `#3306 The Surprising Downfall of Google`,
`#627 A global capital for AI safety…`, `#1851 Claude Opus 5 … AI Videos`.

## Что сделать

- Для каждой из шести позиций выяснить, какой терм сработал
  (диагностика через explain-подход из classify, при необходимости
  добавить аналогичный `explainInventionMatch`).
- Удалить/уточнить виновные термы; кандидаты на удаление по коду:
  «автономн…» уже удалён, проверить «робот…» (робот-новости без
  научно-исследовательского контекста), «телескоп/галактик» в
  развлекательном контексте, «климат(ическ)» в новостях про ESG-риторику.
- Правило: терм остаётся, только если хотя бы один реальный AI-for-science
  кейс им ловится и ни один из шести негативов больше не ловится.
- Обновить тесты: шесть негативов из этого тикета + существующие позитивы
  (AlphaFold, CRISPR+ML, «ИИ открыл материал») остаются зелёными.

## Итог (26.08.2026)

Виновник оказался не в термах, а в подаче полного текста: транскрипты почти
всегда содержат «ДНК/protein/quantum» в метафорах и попутных упоминаниях.
`resolveSection` больше не скармливает контент invention-классификатору —
только заголовок+описание (как и для науки). Все шесть негативов вышли
из invention-tools; `explainInventionMatch` добавлен для диагностики
(итерация по массиву альтернатив — split исходника regex рвёт `(?:...)`).

Повторный бэкфилл: 28 строк покинули раздел (21 → ai-news, 7 → science),
распределение: ai-news 218 / science 36 / invention-tools 16. Побочный
эффект: пара пограничных кейсов («Why AI systems are most useful as
designers of new scientific tools») ушла в ai-news — сознательный trade-off
в пользу чистоты раздела.
