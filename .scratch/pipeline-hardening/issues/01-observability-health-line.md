# Тикет 01: Наблюдаемость — health фидов и строка здоровья в дайджесте

Status: done
Blocked by: —

## Проблема

collect-dual молча глотает отказы фидов (science.org 403 длится неделями).
Сбой конвейера (pm2 умер, Zen исчерпан, DB недоступна) виден только по тишине.
В цикле 25.08 3 из 4 Zen-ключей упёрлись в квоту — без видимого следа.

## Что сделать

- `collect-dual.ts`: по каждому фиду/источнику писать результат в
  `source_health` (таблица существует, используется parseAgent): статус,
  счётчики найденных/вставленных, последняя ошибка. Не падать при недоступной
  таблице — health вторичен относительно сбора.
- Новый скрипт `scripts/hermes/pipeline-health.ts`: за последние 24ч —
  собрано / оценено / опубликовано / ошибок по стадиям, состояние фидов
  (ок/падает N циклов), остаток живых Zen-ключей (легковесный ping), возраст
  последней публикации.
- `daily-digest.ts`: перед секциями добавлять строку здоровья, например
  `⚙️ Конвейер: собрано 210 · опубликовано 46 · ошибок 4 · фиды 12/13 · Zen 1/4`.
  Деградация (0 публикаций при живых фидах, все ключи мертвы, фид падает
  > 3 циклов) помечается ⚠️ в этой строке.

## Acceptance criteria

- Дайджест любого утра показывает здоровье конвейера и источников.
- Падение фида видно в дайджесте на следующее утро.
- `tsc -b`, `vitest run` зелёные; тест на сборку строки здоровья.
