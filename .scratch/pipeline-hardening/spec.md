# Спецификация: укрепление конвейера (pipeline-hardening)

## Контекст

После эпика `science-relevance-fixes` (25.08.2026, деплой на прод) ядро
конвейера здорово: единый гейт, жёсткий ИИ-фильтр, трёхсторонняя маршрутизация,
бэкфилл 165 карточек, дайджест с heartbeat. Первый цикл на новом коде:
31 опубликовано, разделы `ai-news` 197 / `invention-tools` 41 / `science` 29.

Код-ревью и наблюдения с прода выявили системные слабые места следующего
уровня. Факты, на которые опираемся:

- Дедуп: Левенштейн ≥ 0.85 только по последним 20 заголовкам БД — при объёме
  ~46 публикаций/сутки дубли одного инфоповода от разных СМИ неизбежны.
- Наблюдаемость: collect-dual не ведёт health по фидам; science.org давно
  отдаёт 403 датацентровым IP, и это видно только чтением исходников.
  Сбой pm2/DB/Zen обнаруживается только по тишине дайджеста.
- В цикле 25.08: 4 fetch-ошибки (Cloudflare/пейволлы); `scrapegraph-fallback.ts`
  — заглушка. Whisper-fallback требует `GROQ_API_KEY` — наличие на проде
  не проверено; без него видео без субтитров отклоняются молча.
- `check-urls.ts` (GC мёртвых ссылок) запускается только вручную.
- Классификаторы словарные: остаточный шум ~2–3% саммари («лечение багов»,
  «робототехники», «организм» в философском эссе); в «изобретения» ещё
  проходят стримы-пустышки (3–4 позиции бэкфилла: «AI NEWS LIVE» и т.п.).
- В цикле 25.08 исчерпались 3 из 4 Zen-ключей — пул спасла ротация и
  fallback-модель, но видимой отчётности по этому нет.
- Безопасность: пароль root `1111111111`, auth.log показывает постоянный
  брутфорс; парольный вход SSH включён.

## Решения

- Наблюдаемость строится на уже существующем утреннем дайджесте: он получает
  строку здоровья конвейера и источников. Отдельных алерт-каналов не создаём.
- Health фидов пишется в существующую таблицу `source_health` (она уже есть
  и используется parseAgent) — без новых таблиц.
- Дедуп усиливается без LLM: шире lookback, нормализация сущностей
  (названия моделей/компаний), порог пересматривается по данным.
- Fetch получает честный fallback-цепочку (повтор с браузерным UA →
  альтернативный extractor), факты отказов фиксируются в metrics.
- LLM-второе-мнение для пограничных статей — отдельный тикет, включается
  только после решения по токен-бюджету.
- SSH-харденинг — серверная операция с подтверждения владельца.

## Не входит в объём

- Перевод классификации целиком на LLM (дорого, детерминизм теряется).
- Новые источники сбора, изменение дизайна дашборда.
- Алерт-бот/отдельный канал уведомлений.
- Деплой-инфраструктура (Docker/nginx) — работает, не трогаем.

## Проверка готовности

- `cd app && npx tsc -b` и `npx vitest run` — зелёные.
- Утренний дайджест содержит строку здоровья (конвейер + фиды).
- Серверный cron дополнен еженедельным check-urls (dry-run с логом).
- Дедуп: тесты на дубли одного инфоповода в разной формулировке.
- Все изменения задеплоены по действующей схеме (rsync → build → pm2).
