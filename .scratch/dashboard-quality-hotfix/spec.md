# Спека: хотфикс дайджеста и чистка данных (dashboard-quality-hotfix)

Контекст: 2026-08-20 08:00 МСК владельцу ушёл тестовый дайджест со старым форматом
и мусорным содержимым. Три жалобы клиента: (1.1) превью без описания — только
название + теги; (1.2) нерелевантные статьи (косатки, Филдс, визы) в «ИИ для науки»
и «Инструментах для изобретений»; (1.3) июльские даты в дашборде при фильтре
«За сутки».

## Корневые причины (подтверждены на сервере)

1. **Деплой не выполнен.** Коммиты 3b9d7c7..0764b67 запушены в git, но не
   развернуты на сервере: на сервере нет `api/queries/newsDateRules.ts`, в
   `classify.ts` нет AI-сигнала, `daily-digest.ts` — старая версия.
2. **Мусор в БД.** Cron `publish_daily_batch.py` (ежедневно 05:50 UTC)
   публикует до 19 статей со статусом `summarized`, публикуя их `updatedAt=NOW()`.
   Старая классификация (без AI-фильтра) завела в пул Nature d41586-новости
   (новостная лента, не ИИ): косатки, премия Филдса, визы аспирантов и т.п.
   Сегодня паблишер выложил пачку старых июльских статей — они попали в
   «последние 24 часа» и в дайджест.
3. **Формат превью.** Старый `formatSection` писал теги вместо описания для
   не-YouTube секций. В `main` уже исправлено (7b31b25): `— описание` из summary.
   Требуется только деплой.

## Решения (по жалобам клиента)

- **1.1** Превью: `▫️ Название (@url:...) — краткое описание` — уже в `main`.
- **1.2** Классифification: строгий AI-фильтр — уже в `main` (0388146). Дополнительно:
  переклассифицировать накопленный пул `summarized`/`pending` по новым правилам,
  чтобы паблишер завтра не выложил ещё мусора.
- **1.3** Даты: `updatedAt`-фильтр и сортировка — уже в `main` (3b9d7c7). Мусорные
  записи с июльским `publishedAt`, опубликованные сегодня, попадают в окно 24ч —
  лечится чисткой БД (п.2) + деплоем.

## Out of scope

- Разделение на три Telegram-бота (отдельное решение руководителя).
- Полный backfill всего массива `published` статей (только очистка очевidного
  мусора по правилам новых фильтров).
- Изменение расписания дайджеста (остаётся 09:00 МСК).
